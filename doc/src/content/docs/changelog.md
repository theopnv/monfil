Monfil is in early development. See the [GitHub releases](https://github.com/theopnv/monfil/releases) for downloads and full release notes.

## v0.0.6 — September 28, 2026

- Improved the article reader.
- Fixed keyboard shortcuts while renaming a folder.
- Changed the project license to Business Source License 1.1. Earlier releases keep their original MIT license.

[Full release notes](https://github.com/theopnv/monfil/releases/tag/v0.0.6)

## v0.0.5 — September 23, 2026

- Added feedpacks, which let you start with a curated set of sources.
- Added support for RDF and JSON feeds.
- Added automatic removal of old items after the retention period.
- Improved feed requests and background processing.

[Full release notes](https://github.com/theopnv/monfil/releases/tag/v0.0.5)

## v0.0.4 — September 21, 2026

- Added folders and workspaces to organize feeds.
- Added OPML import and export.
- Improved app security and release checks.

[Full release notes](https://github.com/theopnv/monfil/releases/tag/v0.0.4)

## v0.0.3 — September 14, 2026

- Improved the performance of the article list by loading items in pages.
- Fixed the release process.

[Full release notes](https://github.com/theopnv/monfil/releases/tag/v0.0.3)

## v0.0.2 — September 13, 2026

- Added RSS and YouTube feeds, a Home page, and settings.
- Added the article reader, including full article content.
- Added feed images, favicons, refresh, and feed removal.

[Full release notes](https://github.com/theopnv/monfil/releases/tag/v0.0.2)

## v0.0.1 — August 7, 2026

First preview release.

[Release page](https://github.com/theopnv/monfil/releases/tag/v0.0.1)
