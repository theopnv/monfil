---
title: 搜索与已保存的搜索
description: 使用短语、OR、排除项和标题搜索信息流，并将搜索保留为信息流上方的标签。
---

信息流上方的搜索框会筛选当前 Workspace 中的项目。它对每个来源的工作方式都相同。

## 搜索语法

| 类型 | Monfil 显示 |
| --- | --- |
| `rust async` | 同时包含这两个词的项目 |
| `"machine learning"` | 包含完整短语的项目 |
| `kubernetes OR k8s` | 包含任一词的项目。`OR` 必须大写。 |
| `-sponsored` | 不包含该词的项目。也可用于短语：`-"press release"`。 |
| `title:release` | 标题中包含该词的项目。也可用于短语：`title:"release notes"`。 |

你可以组合这些写法：`title:"release notes" -beta`。`go OR rust OR zig` 这样的链式写法也可以使用。不支持括号，`-` 开头的词不能成为 `OR` 的一部分。单词内部的连字符（例如 `front-end`）属于该单词的一部分。

三个字母或更少的词（例如 `ci`）只匹配完整单词，因此不会找到 `producing`。其他词也会匹配较长单词的内部，因此 `engineer` 会找到 `engineers`。如果希望短词也匹配单词内部，请将其放在引号中，例如 `"ci"`。

不带 `title:` 时，Monfil 会搜索标题、文本的前 200 个字符，以及订阅源名称。对于职位，它还会搜索地点和工作模式。它不会搜索项目的完整文本。

## 保存搜索

1. 输入搜索词。搜索框旁边会出现 **保存搜索** 按钮。
2. 选择 **保存搜索**，输入名称，然后按回车键。

该搜索现在会成为信息流上方的标签。标签上的数字是与之匹配的未读项目数。标签属于你创建它们的 Workspace。

- 选择标签即可运行其搜索。再次选择它即可清除搜索。
- 标签会显示已读和未读项目，因此项目在你阅读后的几天内仍会留在其搜索结果中。选择 **未读** 可再次隐藏已读项目。
- 指向标签并选择叉号即可删除它。
- 右键单击标签，或将焦点放在标签上并按 F2 键，即可重命名。
- 如果你更改了已选中标签的搜索词，**更新** 会更改该标签。**另存为新搜索** 会创建第二个标签。
- 当标签多到一行放不下时，可以横向滚动该行，或选择三个点的菜单以查看全部标签。
