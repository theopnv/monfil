你可以像关注博客一样关注公司的在招职位。每个在招职位都是信息流中的一张卡片。

## 关注公司的职位

选择订阅源栏顶部的 **+**，选择 **招聘** 芯片，然后粘贴该公司的招聘板。[支持的来源](../supported-sources/#招聘)页面列出了 Monfil 可读取的招聘系统。

你也可以安装 Feedpack。这些 Feedpack 会一次列出许多公司的招聘板：

- Tech Jobs
- Video Game Jobs
- Finance Jobs

部分雇主使用 Monfil 尚不支持读取的招聘系统。这些雇主不在 Feedpack 中。

## 查找你想要的职位

Monfil 会列出公司在每个国家、每个办公地点的所有职位。使用[搜索框](../search/)，即可只保留你想要的职位和地点。以下写法适用于职位搜索：

| 类型 | Monfil 显示 |
| --- | --- |
| `title:engineer` | 职位名称中包含 `engineer` 的职位。不带 `title:` 时，搜索还会匹配地点、工作模式、公司名称和职位描述的开头部分。 |
| `title:"data analyst" -senior` | 数据分析师职位，不包括高级职位 |
| `title:designer OR title:researcher` | 任一角色 |
| `paris` | 巴黎的职位。Monfil 会搜索职位所在的地点。 |
| `remote` | 远程职位 |
| `title:engineer paris -senior` | 巴黎的工程师职位，不包括高级职位 |
| `-intern` | 不包括实习职位 |

为你想要的每个角色保存一个搜索。标签会保留该搜索，其计数显示与之匹配的未读职位数。阅读后，职位仍会留在其搜索结果中，因此你可以在之后几天再回来查看。请参见[搜索和已保存的搜索](../search/#保存搜索)。

只要保留设置允许，职位就会一直留在信息流中。公司招满后，Monfil 不会删除该职位。
