## ドキュメントサイト

このサイトは [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) を使って、訪問数とページの読み込み性能を計測しています。Monfilのメンテナーは、この統計を使ってドキュメントを改善し、読み込みの遅いページを見つけます。

分析レポートには、ページのパス、参照元のサイト、国、ブラウザー、OS、デバイスの種類、ページの読み込み時間が含まれます。ブラウザーは Cloudflare からスクリプトを読み込み、計測値を Cloudflare に送信します。これらのリクエストを行うと、Cloudflare が IP アドレスを受け取ります。Cloudflare の分析レポートは、IP アドレスをメンテナーに提供しません。

Cloudflare によると、Web Analytics は利用状況の指標を集めるために、クッキーやローカルストレージを使いません。フィンガープリンティングによって訪問者を識別することもありません。複数のサイトをまたいで訪問者を追跡することもありません。詳しくは、[データ収集に関するドキュメント](https://developers.cloudflare.com/web-analytics/data-metrics/data-origin-and-collection/) を参照してください。

Cloudflare は、サンプリングされていない分析データを7日間保持します。その後は、長期の統計にサンプリングされたデータを使います。ダッシュボードでは、過去6か月分にアクセスできます。サンプリングとレポートへのアクセス期間については、[Web Analytics FAQ](https://developers.cloudflare.com/web-analytics/faq/) を参照してください。

Cloudflare, Inc. は米国に拠点を置いています。その[プライバシーポリシー](https://www.cloudflare.com/privacypolicy/) では、リクエストデータの扱い、個人データの保持期間、欧州経済領域外への転送時に使う保護措置を説明しています。

### ウェブサイトのホスティングとブラウザーのストレージ

Cloudflare がこのウェブサイトをホストしています。ページを開くと、Cloudflare が IP アドレスとリクエストの詳細を受け取ります。詳しくは、[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/) を参照してください。

このウェブサイトは、選択したカラーテーマをブラウザーのローカルストレージに保存します。この設定は、変更するか、サイトの保存データを消去するまで端末に残ります。これは Cloudflare の分析とは別のものです。

ブラウザーや広告ブロッカーで Cloudflare のスクリプトをブロックしても、ドキュメントは引き続き読めます。

### プライバシーに関する質問と権利

Monfilのウェブサイトのメンテナーが、このウェブサイトに責任を負います。プライバシーに関する質問や、個人データに関するリクエストは、[hello@monfil.app](mailto:hello@monfil.app) にメールで送ってください。

## デスクトップアプリ

Monfilは、デスクトップのフィードリーダーです。アカウントも、Monfilのサーバーもありません。フィード、保存した記事、既読の状態は、お使いの端末に保存されます。一部の表示設定は、ローカルストレージを使います。データベースは、設定から確認やバックアップができます。

### 匿名の利用統計とエラーレポート（任意）

Monfilは、匿名の利用統計とエラーレポートを送信できます。1つの設定で両方を管理します。同意するまでは、どちらも送信されません。Monfilを初めて開くと、同じ大きさの **統計とレポートを送信** と **いいえ、結構です** の2つのボタンがあるカードが表示されます。拒否したりカードを閉じたりすると、Monfilは30日後にもう一度確認し、同意するまで30日ごとに確認します。選択は、いつでも **設定 > プライバシー** で変更できます。**送信される内容を見る** では、Monfilが今日送信する概要と、エラーレポートの例を確認できます。

#### 利用統計

同意すると、Monfilは端末上で、あなたの操作を集計します。1日に1回、使用した日ごとに `daily_summary` イベントを1件送信します。同意したときは、データを含まない `consent_granted` イベントも1件送信します。`daily_summary` イベントには、次の内容が含まれます:

- その日の件数: 開いた記事、全文の取得、追加したフィード、削除したフィード、手動更新、保存した項目、インストールしたフィードパック、インポートした OPML ファイル、エクスポートした OPML ファイル、作成したバックアップ、作成したワークスペース、切り替えたワークスペース、検索、読み込んだ埋め込み。
- その日の失敗件数: フィードの更新失敗、記事の取得失敗、内部リクエストの失敗、インターフェースの失敗。これらは数値だけで、エラーの文字列は含みません。フィードの更新エラーは、原因別にも集計されます。タイムアウト、HTTP 4xx、HTTP 5xx、TLS、DNS、解析、サイズ超過です。
- アプリの起動: 起動できたかどうかと、最初の記事を表示するまでの時間の範囲（1秒未満、1〜3秒、3〜10秒、10秒超）。
- フィードの追加: 試行回数と成功回数、および原因別の失敗回数（フィードが見つからない、ネットワーク、解析、非対応）。
- ライブラリの状態: フィード数の範囲（`0`、`1-5`、`6-20`、`21-100`、`100+` のいずれか）、ワークスペース数、フォルダ数、使用しているフィードの種類（`rss+youtube` など）。
- 表示設定: 表示密度、テーマ、Monfilの表示言語、既読の項目を非表示にするかどうか、スクロール時に既読にするかどうか、リンクをブラウザーで開くかどうか、キーボード操作をオンにしているかどうか。
- 集計対象の日付、Monfilのバージョン、OS とそのバージョン、言語設定、Monfilが使用している Web エンジンのバージョン。

このイベントには、フィード名、リンク、記事の本文、検索語、あなたの名前は含まれません。永続的な識別子も送信しません。リクエストごとに、新しいランダムなセッション ID を使います。

[Aptabase](https://aptabase.com) がイベントを受け取ります。ルーマニアのブカレストに拠点を置く Technov Solutions SRL が、Aptabase を運営しています。同社は、[データ処理契約](https://aptabase.com/legal/dpa) に基づき、Monfilのメンテナーのための処理者として動作します。Monfilは EU リージョン（`eu.aptabase.com`）を使用します。Aptabase によると、EU リージョンのアカウントのデータは、EU 内でのみ処理と保存を行います。

Aptabase は、サーバー上で、IP アドレスとユーザーエージェントをソルト付きでハッシュ化し、匿名のユーザー ID を作成します。Aptabase によると、ソルトはアプリごとに異なり、24時間ごとに破棄されます。ID は毎日変わるため、メンテナーはある人を1日から次の日まで追跡できません。Aptabase によると、分析データは最長で5年間保持されます。詳しくは、[Aptabase のプライバシーポリシー](https://aptabase.com/legal/privacy) を参照してください。

#### エラーレポート

同意すると、Monfilは何かが失敗したときにレポートを送信します。たとえば、アプリ内のエラー、更新の失敗、データベースの復旧、クラッシュです。レポートには次の内容が含まれます。

- エラーの種類、エラーメッセージ、スタックトレース（Monfilのコード内の場所の一覧）。
- エラー画面に表示されるものと同じ短いインシデントID、および失敗したアプリの部分（たとえば内部リクエストの名前）。
- 失敗の直前にMonfilで起きた最近のイベントの短い記録。イベント名と、`outcome: failed` のような固定の値だけが含まれます。フィード名、リンク、フィードや記事のIDは含まれません。
- Monfilのバージョン、ビルドの入手元（GitHubかストアか）、OSとそのバージョン、プロセッサーの種類、Monfilに含まれるWebエンジンとNode.jsのバージョン。
- クラッシュせずに終了したセッションの数を知るためのセッションデータ: セッションの開始時刻、継続時間、正常に終了したかどうか。

レポートを送信する前に、Monfilはエラーの文章からファイルのパス（ホームフォルダーは `~` になります）、リンク、メールアドレスを削除します。上の一覧にある項目だけを送信し、それ以外は破棄します。レポートには、フィード名、リンク、記事の本文、検索語、ユーザー名、Monfilが追加するIPアドレスは含まれません。**送信される内容を見る** では、架空の障害をもとにMonfilがこの端末で作成したレポートの例を確認できます。

Monfilが低いレベルでクラッシュした場合は、クラッシュダンプも送信します。クラッシュダンプは、クラッシュしたプロセスのメモリのスナップショットです。メモリには、記事のタイトルなど、アプリが表示していた内容の一部が残っていることがあります。Monfilはそれらを削除できません。

失敗のあと、レポートに詳細を追加できます。コメントは任意で、自分で書きます。ログファイルは、**ログファイルを添付** にチェックを入れた場合にだけ添付され、送信前にプレビューできます。ログファイルにはMonfilのイベント記録が含まれ、フィード名、完全なリンク、記事の本文、認証情報、ファイルのパスは削除されています。サイトのホスト名やエラーコードは残ることがあります。Monfilは末尾の1 MBを添付します。テキスト欄のないOS標準のエラーウィンドウでは、ログファイルだけを選べます。

[Sentry](https://sentry.io) がレポートを受け取ります。米国に拠点を置く Functional Software, Inc. が Sentry を運営しています。同社は、その[データ処理契約](https://sentry.io/legal/dpa/)に基づき、Monfilのメンテナーの処理者として動きます。MonfilはEUリージョン（`de.sentry.io`）を使い、Sentryはデータをドイツに保存します。Sentryはリクエストのたびにあなたの IP アドレスを受け取りますが、Monfilのプロジェクトは保存しない設定です。Sentryはエラーレポートを30日間保管します。新しい問題が現れると、メンテナーにメールが届きます。

#### あなたの選択

法的根拠は、あなたの同意です。選択内容は、日付とこの通知のバージョンとともに、端末に保存されます。同意を撤回するには、設定で **匿名の利用統計とエラーレポートを送信** をオフにします。すると、Monfilは集計と送信を止め、端末に保存した件数、送信待ちのレポート、クラッシュダンプを削除します。すでに受信したレポートは、あなたに結び付けられません。ただし、レポートのインシデントIDをメンテナーに伝えた場合は別です。データについて問い合わせるには、[hello@monfil.app](mailto:hello@monfil.app) にメールしてください。分析キーとエラーレポートの宛先がないMonfilのビルド（自分でコンパイルしたビルドなど）は、何も送信しません。

### 他のサイトへのリクエスト

Monfilは、フィードを更新するときに、発行元にフィードを要求します。記事を開くと、全文を取得するために、発行元のページにリクエストすることがあります。画像やフィードのアイコンは、画面に表示されたときに、リモートサイトから読み込まれることがあります。それらのサイトはリクエストを受け取り、IP アドレスやアプリまたはブラウザーの情報などを知ることができます。

フィードを追加すると、Monfilは貼り付けたページと、同じサイト上の一般的なフィードのアドレスにリクエストすることがあります。Hacker News のリンクの場合は、[hnrss.org](https://hnrss.org) のフィードを確認します。GitLab プロジェクトや Bluesky プロフィールのアイコンを表示するために、GitLab API または Bluesky の公開 API にアバターを要求します。カンファレンスのフィードは、追加時と更新のたびに、[developers.events](https://developers.events) からイベント一覧を要求します。このイベント一覧は、GitHub Pages がホストしています。

記事やほかのリンクをブラウザーで開くと、リンク先のサイトにも接続します。そのブラウザーは、独自のプライバシー設定を使います。

### 埋め込みメディア

Monfilは、YouTube、X、Vimeo、Instagram、Spotify の埋め込みに対応しています。最初にカードを表示します。カードの **読み込む** を選んだあとで初めて、Monfilは提供元の埋め込みフレームを作成します。埋め込みごとに、記事を開くたびにクリックが必要です。埋め込みを読み込まずに、記事を読むこともできます。

埋め込みを読み込むと、端末が提供元に接続します。提供元は、その動画、投稿、または音声の項目へのリクエストを受け取ります。提供元は、IP アドレスやアプリまたはブラウザーの情報を知ることができます。フレーム内でクッキーやほかのストレージを使う場合もあります。Monfilは、提供元のデータの扱いを管理していません。提供元で開くリンクをクリックすると、ブラウザーで提供元に接続します。

埋め込みを読み込んでも、記事の画像やフィードのアイコンが、それぞれのサイトから読み込まれることは止まりません。

提供元のプライバシーポリシー: [YouTube（Google）](https://policies.google.com/privacy)、[X](https://x.com/en/privacy)、[Vimeo](https://vimeo.com/legal/privacy)、[Instagram（Meta）](https://www.facebook.com/privacy/policy/)、[Spotify](https://www.spotify.com/legal/privacy-policy/)。
