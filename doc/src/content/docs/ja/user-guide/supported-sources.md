---
title: 対応しているソース
description: フィードを追加画面に貼り付けられるものと、各ソースでMonfilが追跡する内容。
---

フィードのサイドバー上部で **+** を選択し、**フィードを追加** を開きます。ボックスにリンクを貼り付けます。Monfilがリンクの先にあるフィードを探します。フィードのURLそのものは不要です。

ボックスの下にあるチップで、ソースの種類を指定します。Monfilに種類を自動で判定させる場合は、**すべて** のままにします。判定できない場合や、ハンドルのような短い形式を入力する場合は、チップを選びます。ハンドルの場合は、Enter を押して確認を開始します。

リンクによっては、複数のフィードが見つかります。その場合は、Monfilが一覧を表示し、最初のフィードを選択します。使いたいフィードを選び、**続ける** を選択します。

## Webサイトとブログ

サイトの任意のページのアドレスを貼り付けます。Monfilは、ページが公開しているフィードのリンクを読み取ります。リンクがない場合、Monfilは同じサイト上の一般的なフィードのアドレス（`/feed` や `/rss.xml` など）を試します。

## GitHub

| 貼り付け | Monfilが追跡する内容 |
| --- | --- |
| リポジトリ（`github.com/microsoft/playwright` など） | そのリポジトリのリリース |
| ユーザーまたは組織（`github.com/torvalds` など） | 公開アクティビティ |
| **GitHub** チップを選んだ状態で `owner/repo` | そのリポジトリのリリース |

## GitLab

プロジェクトのリンク（例: `gitlab.com/gitlab-org/gitlab`）を貼り付けます。Monfilはプロジェクトのリリースを追跡します。セルフホストの GitLab の場合は、先に **GitLab** チップを選びます。

## Hacker News

`news.ycombinator.com` を貼り付けます。Monfilは次のフィードを提供します:

- **トップページ**。Hacker News 自体から取得します。既定の選択です。
- **100ポイント以上** と **300ポイント以上**。そのスコアに達した記事だけを表示します。
- **Show HN** と **Ask HN**。

後ろの4つは、Hacker News の一部ではない無料のサービス [hnrss.org](https://hnrss.org) から取得します。`news.ycombinator.com/show` のようにセクションへのリンクを貼ると、そのセクションだけが表示されます。

## arXiv

カテゴリの一覧（例: `arxiv.org/list/cs.AI/recent`）を貼り付けます。Monfilは、そのカテゴリの日次の新着情報をフォローします。差し替えられた論文は非表示にします。これらは、すでに見た論文の新しいバージョンだからです。arXiv は週末に公開しません。

## アカウントなしの Bluesky と Mastodon

Bluesky や Mastodon の人をフォローするために、アカウントは不要です。どちらのネットワークも、公開プロフィールごとにフィードを公開しており、Monfilはそれを読み取ります。[利用例](../use-cases/#アカウントなしで人をフォローする) を参照してください。

## Bluesky

プロフィールのリンク（例: `bsky.app/profile/bsky.app`）、またはハンドル（例: `@name.bsky.social`）を貼り付けます。`@` を付けずにカスタムドメインのハンドルを使う場合は、**Bluesky** チップを選びます。

## Mastodon

ハンドル（例: `@user@mastodon.social`）を貼り付けます。任意のサーバーのプロフィールリンクやタグのリンクも貼り付けられます（例: `hachyderm.io/@user`、`hachyderm.io/tags/rust`）。

## YouTube

チャンネル、ハンドル、動画、再生リストのリンクを貼り付けます。動画のリンクを貼ると、その動画を投稿したチャンネルをフォローします。

## 開発者向けカンファレンス

**カンファレンス** チップを選びます。トピックを入力し、`in` を入力してから、場所を入力して Enter を押します。各リストの項目はカンマで区切ります。場所は任意です。オンラインのイベントには `online` を使います。

| 種類 | Monfilが追跡する内容 |
| --- | --- |
| `devops` | すべての場所の DevOps カンファレンス |
| `kubernetes, cloud in France` | フランスで開催される Kubernetes またはクラウドのカンファレンス |
| `java in Belgium, online` | ベルギーまたはオンラインで開催される Java のカンファレンス |

トピックは、`java` や `devops` のようなカンファレンスのタグと一致します。Monfilはトピック内のスペースをハイフンに変換するため、`software testing` は `software-testing` タグを見つけます。場所は、都市または国と一致します。

[developers.events](https://developers.events) のリンクは、チップなしでも貼り付けられます。先にサイトでフィルターを設定してから、アドレスをコピーします。Monfilは、国、トピック、技術、言語のフィルターを使います。アドレス内の年は無視し、すべての年のカンファレンスを表示します。地域など、ほかのフィルターがリンクに含まれる場合は、Monfilがそのフィルターを削除するよう案内します。

どのカンファレンスもトピックや場所に一致しない場合、Monfilはその旨を伝え、近い候補を提案します。たとえば `test automation` の場合は、`testing` を提案します。トピックと場所は正しいものの、現時点で一致するカンファレンスがない場合も、Monfilはその旨を伝えます。それでもフィードは追加できます。一致するカンファレンスが発表されると、カードが表示されます。

次のいずれかのイベントが発生すると、Monfilはタイムラインにカードを追加します:

- カンファレンスが今後12か月以内に始まる。
- カンファレンスの発表論文の募集（CFP）が始まる。
- CFP の締め切りが14日以内に来る。
- 30日後に開始する。
- 今日開始する。

フィードを追加すると、すでに発生しているイベントごとにカードが表示されます。Monfilは、更新のたびに developers.events からデータを読み取ります。全イベント一覧のコピーは保持しません。このデータは [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) ライセンスで提供されており、各カードには情報源が表示されます。

## 求人

**求人** チップを選びます。企業の求人ボード（例: `jobs.lever.co/spotify` や `boards.greenhouse.io/datadog`）を貼り付けます。企業の採用ページを貼り付けることもできます。Monfilは、そのページから対応している求人ボードへのリンクを探します（うまくいかない場合もあります）。

Monfilは次の求人システムの公開求人ボードを読み取ります:

- Greenhouse
- Lever
- Ashby
- Workable
- SmartRecruiters
- Recruitee
- Teamtailor
- Personio

Workday などほかのシステムには、まだ対応していません。そのため、対応範囲は完全ではありません。

公開中の求人は、それぞれ1枚のカードになります。カードには、企業名、勤務地、勤務形態、求人票に記載がある場合は給与が表示されます。給与は、求人票にあれば Monfilが読み取ります。

Monfilは企業のすべての求人を表示します。ほしい職種だけに絞るには、職種ごとに検索を保存します。[求人](../jobs/) を参照してください。

求人は、保持設定が残す限りタイムラインに残ります。企業が募集を終えても、Monfilは求人を削除しません。

## Substack

発行元のアドレス（例: `name.substack.com` またはそのカスタムドメイン）を貼り付けます。Monfilがフィードを探します。アドレスの末尾に `/feed` を自分で付けることもできます。

## Google Alerts

1. [Google アラート](https://www.google.com/alerts) を開き、アラートを作成します。
2. **オプションを表示** を選択します。**配信先** を **RSS フィード** に設定します。
3. **アラートを作成** を選択します。アラート一覧から RSS のリンクをコピーし、Monfilに貼り付けます。

## 対応していないソース

X はフィードを公開していません。Reddit は RSS フィードを終了しているため、Monfilは対応していません。
