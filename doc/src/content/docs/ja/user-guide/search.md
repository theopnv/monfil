---
title: 検索と保存済み検索
description: フレーズ、OR、除外、タイトル指定で検索し、検索をタイムラインの上にピルとして保存します。
---

タイムラインの上にある検索ボックスは、現在のワークスペースの項目を絞り込みます。すべてのソースで同じように動作します。

## 検索の構文

| 種類 | Monfilの表示 |
| --- | --- |
| `rust async` | 両方の単語を含む項目 |
| `"machine learning"` | 完全に一致するフレーズを含む項目 |
| `kubernetes OR k8s` | どちらかの単語を含む項目。`OR` は大文字で書きます。 |
| `-sponsored` | その単語を含まない項目。フレーズにも使えます: `-"press release"`。 |
| `title:release` | タイトルに単語を含む項目。フレーズにも使えます: `title:"release notes"`。 |

これらの書き方は組み合わせられます: `title:"release notes" -beta`。`go OR rust OR zig` のような並びも使えます。括弧は使えず、`-` の付いた単語を `OR` の一部にはできません。`front-end` のように単語の中にあるハイフンは、単語の一部として扱われます。

`ci` のように3文字以下の単語は、単語単位でのみ一致します。そのため `producing` は見つかりません。それ以外の単語は、長い単語の中でも一致します。そのため `engineer` は `engineers` を見つけます。短い単語も長い単語の中で一致させたい場合は、`"ci"` のように引用符で囲みます。

`title:` を付けない場合、Monfilはタイトル、本文の最初の200文字、フィード名を検索します。求人の場合は、勤務地と勤務形態も検索します。項目の全文は検索しません。

## 検索を保存する

1. 検索語を入力します。検索ボックスの横に **検索を保存** ボタンが表示されます。
2. **検索を保存** を選択し、名前を入力して Enter を押します。

検索は、タイムラインの上にピルとして表示されます。ピルの数字は、一致する未読の項目数です。ピルは、作成したワークスペースに属します。

- ピルを選ぶと、その検索を実行します。もう一度選ぶと、検索が解除されます。
- ピルには既読と未読の両方の項目が表示されるため、読んだ後の日も、項目は検索に残ります。既読の項目を隠すには、**未読** を選択します。
- ピルにポインターを合わせて、×を選択すると削除できます。
- ピルを右クリックするか、フォーカスして F2 を押すと、名前を変更できます。
- 選択中のピルの検索語を変更した場合、**更新** を選ぶとそのピルが変わります。**新規保存** を選ぶと、2つ目のピルが作成されます。
- ピルの数が行に収まらない場合は、行を横にスクロールするか、三つの点のメニューを選ぶと、すべてのピルを表示できます。
