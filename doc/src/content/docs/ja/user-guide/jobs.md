企業の公開中の求人を、ブログと同じようにフォローできます。公開中の求人は、それぞれタイムラインに1枚のカードとして表示されます。

## 企業の求人をフォローする

フィードのサイドバー上部で **+** を選択し、**求人** チップを選んで、企業の求人ボードを貼り付けます。[対応しているソース](../supported-sources/#求人) のページに、Monfilが読み取れる求人システムの一覧があります。

フィードパックをインストールすることもできます。これらのパックには、多くの企業の求人ボードが一覧されています:

- Tech Jobs
- Video Game Jobs
- Finance Jobs

一部の企業は、Monfilがまだ読み取れない求人システムを使っています。そうした企業は、パックには含まれていません。

## ほしい職種を見つける

Monfilは、企業のすべての拠点とすべての国の求人を一覧します。[検索ボックス](../search/) を使うと、ほしい職種と勤務地だけに絞り込めます。求人には次の書き方が便利です:

| 種類 | Monfilの表示 |
| --- | --- |
| `title:engineer` | 求人タイトルに `engineer` を含む求人です。`title:` を付けない場合、検索は勤務地、勤務形態、企業名、説明文の冒頭も対象にします。 |
| `title:"data analyst" -senior` | data analyst の求人のうち、senior を除いたもの |
| `title:designer OR title:researcher` | どちらかの職種 |
| `paris` | パリの求人です。Monfilは求人の勤務地を検索します。 |
| `remote` | リモート勤務の求人 |
| `title:engineer paris -senior` | パリの engineer の求人のうち、senior を除いたもの |
| `-intern` | インターンシップを除いたもの |

職種ごとに検索を保存してください。保存した検索はピルとして表示されます。ピルの数字は、その検索に一致する未読の求人数です。求人は、読んだあとも検索に残るため、後日戻って確認できます。詳しくは [検索と保存済み検索](../search/#検索を保存する) を参照してください。

求人は、保持設定が残す限りタイムラインに残ります。企業が募集を終えても、Monfilは求人を削除しません。
