この3人は、それぞれの分野で先を行く必要があります。DevOps エンジニアは、スタックのツールが変わったときに、いち早く知る必要があります。創業者は、競合が出すものと、伸びている傾向を把握する必要があります。研究者は、ほかの人が引用する前に、新しい論文を読まなければなりません。それぞれが、ワークスペースを作成し、**フィードを追加** にいくつかのリンクを貼り付けて、すべてを1つのタイムラインで読みます。設定をコピーしてから、自分の分野に合わせて変更してください。

ソースを追加するには、フィードのサイドバー上部で **+** を選び、リンクを貼り付けます。Monfilがフィードを見つけます。[対応しているソース](../supported-sources/) のページで、ソースごとに貼り付けられるものを確認できます。

## DevOps エンジニア

Sam は中規模の会社でプラットフォームチームを率いています。スタックのツールがリリースされたときに知る必要があり、今週コミュニティで何が話題になっているかも把握したいと考えています。毎朝10のサイトを確認したくはありません。

Sam は、次のソースを含む **プラットフォーム** ワークスペースを作成します。

| フォルダ | 貼り付け | 得られるもの |
| --- | --- | --- |
| リリース | `github.com/kubernetes/kubernetes` | Kubernetes の各リリースと、そのリリースノート |
| リリース | `github.com/opentofu/opentofu` | OpenTofu の各リリース |
| リリース | `github.com/argoproj/argo-cd` | Argo CD の各リリース |
| ブログ | `kubernetes.io/blog` | Kubernetes ブログの投稿 |
| ブログ | `cncf.io/feed` | CNCF ブログの投稿 |
| コミュニティ | `hachyderm.io/tags/kubernetes` | `#kubernetes` タグが付いた Mastodon の投稿 |
| コミュニティ | `fosstodon.org/tags/devops` | `#devops` タグが付いた Mastodon の投稿 |
| コミュニティ | Sam が信頼するエンジニアごとの `@user@hachyderm.io` | その人の投稿 |

Sam は Mastodon のアカウントを持っていません。Monfilは、タグや人の公開フィードを読み取るため、Sam にアカウントは不要です。

リリースノートは項目すべてとして取り込まれるため、Sam は GitHub を開かなくても、変更点を読めます。マイナーリリースに互換性のない変更がある場合、Sam はその項目を保存し、アップグレードのチケットにリンクします。

**ヒント:** Platform Engineering フィードパックには、Kubernetes、OpenTofu、Helm などのツールのリリースがすでに含まれています。インストールしてから、自分のツールを追加してください。

## 創業者

Alex は、オープンソースのウェブ解析製品を1人で開発しています。競合が出すものを把握し、傾向を早く見つける必要があります。時間が限られているため、ワークスペースには強いシグナルだけを入れます。

Alex は、次のソースを含む **マーケット** ワークスペースを作成します。

| フォルダ | 貼り付け | 得られるもの |
| --- | --- | --- |
| 競合 | `github.com/plausible/analytics` | Plausible の各リリース |
| 競合 | `github.com/umami-software/umami` | Umami の各リリース |
| 競合 | 各競合のブログ | 公開記事と発表 |
| トレンド | `news.ycombinator.com`、次に **300ポイント以上** を選択 | 300ポイントに達した記事だけ |
| トレンド | `news.ycombinator.com`、次に **Show HN** を選択 | ほかのビルダーが公開したもの |
| 言及 | 製品名の Google アラートのフィード | 製品名が書かれた新しいページ |
| 人物 | 同じ分野の創業者の `@name.bsky.social` | Bluesky での投稿 |

Hacker News では、複数のフィードから選べます。Alex はポイントのしきい値を選ぶため、タイムラインには全体の流れではなく、多くの人が話題にした記事が表示されます。Google アラートについては、[対応しているソース](../supported-sources/#google-alerts) のページで、フィードの取得方法を確認できます。

Alex のロードマップにある機能を出した競合のリリースは、同じ日に届きます。創業者をフォローするために、Alex に Bluesky のアカウントは必要ありません。

**ヒント:** Founders & Solopreneurs フィードパックには、すでに **Show HN** と **300ポイント以上** のフィードが含まれています。インストールしてから、競合を追加してください。

## 研究者

Priya は大学の研究室で言語モデルを研究しています。毎日、いくつかの分野の新しい論文を読む必要があります。また、研究室が使うライブラリの変更や、新しい論文について他の研究者が何と言っているかも知りたいと考えています。

Priya は、次のソースを含む **リサーチ** ワークスペースを作成します。

| フォルダ | 貼り付け | 得られるもの |
| --- | --- | --- |
| 論文 | `arxiv.org/list/cs.CL/recent` | Computation and Language の新しい論文 |
| 論文 | `arxiv.org/list/cs.LG/recent` | Machine Learning の新しい論文 |
| ライブラリ | `github.com/huggingface/transformers` | Transformers の各リリース |
| ライブラリ | `github.com/pytorch/pytorch` | PyTorch の各リリース |
| 研究室 | `huggingface.co/blog` | Hugging Face ブログの投稿 |
| 人物 | Priya がフォローする各研究者の Bluesky プロフィール | その人の投稿と論文のスレッド |

Monfilは差し替えられた論文の arXiv 告知を非表示にします。そのため、古い論文の新しいバージョンが、再び届くことはありません。arXiv は週末に公開しないため、土曜日と日曜日はタイムラインが静かです。

Priya は検索を使って、複数のカテゴリにわたる1つのテーマの論文をすべて探します。読みたい論文は、**保存済み** の一覧に保存します。

**ヒント:** AI フィードパックには、`cs.AI`、`cs.LG`、`cs.CL` のカテゴリと、主要な AI ライブラリのリリースがすでに含まれています。

## アカウントなしで人をフォローする

Bluesky と Mastodon は、公開プロフィールごとにフィードを公開しています。Mastodon は、サーバー上のタグごとにもフィードを公開しています。Monfilはこれらのフィードを直接読み取ります:

- どちらのネットワークでも、アカウント、アプリ、サインインは不要です。
- 投稿は、タイムラインの他のソースと一緒に届きます。おすすめや「いいね」の数はありません。
- Monfilは公開投稿だけを読み取ります。フォロワー限定の投稿など、サインインが必要な投稿は表示できません。

人をフォローするには、プロフィールのリンクまたはハンドルを貼り付けます。Bluesky の場合は `@name.bsky.social`、Mastodon の場合は `@user@server` を使い、Enter を押します。
