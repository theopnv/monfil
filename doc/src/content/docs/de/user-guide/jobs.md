Sie können die offenen Stellen eines Unternehmens genauso verfolgen wie einen Blog. Jede offene Stelle ist eine Karte im Stream.

## Die Stellen eines Unternehmens verfolgen

Wählen Sie **+** oben in der Feed-Seitenleiste, wählen Sie den Chip **Stellen** und fügen Sie die Stellenbörse des Unternehmens ein. Die Seite [Unterstützte Quellen](../supported-sources/#stellen) zeigt die Stellensysteme, die Monfil liest.

Sie können auch ein Feedpack installieren. Diese Pakete enthalten die Stellenbörsen vieler Unternehmen auf einmal:

- Tech-Stellen
- Stellen in der Spielebranche
- Stellen im Finanzbereich

Manche Arbeitgeber nutzen Stellensysteme, die Monfil noch nicht lesen kann. Diese Arbeitgeber sind nicht in den Paketen enthalten.

## Die gewünschten Rollen finden

Monfil zeigt die Stellen aller Standorte eines Unternehmens in allen Ländern. Nutzen Sie das [Suchfeld](../search/), um nur die Rollen und Orte zu behalten, die Sie möchten. Diese Formen eignen sich gut für Stellen:

| Eingabe | Monfil zeigt |
| --- | --- |
| `title:engineer` | Stellen mit `engineer` im Titel. Ohne `title:` durchsucht die Suche auch den Ort, die Arbeitsform, den Firmennamen und den Anfang der Beschreibung. |
| `title:"data analyst" -senior` | Stellen als Data Analyst, ohne die Senior-Stellen |
| `title:designer OR title:researcher` | Eine der beiden Rollen |
| `paris` | Stellen in Paris. Monfil durchsucht den Ort der Stelle. |
| `remote` | Stellen, die remote sind |
| `title:engineer paris -senior` | Engineer-Stellen in Paris, ohne die Senior-Stellen |
| `-intern` | Ohne Praktika |

Speichern Sie für jede gewünschte Rolle eine Suche. Der Pill behält die Suche, und seine Zahl zeigt die ungelesenen Stellen, die passen. Eine Stelle bleibt nach dem Lesen in ihrer Suche, sodass Sie in den folgenden Tagen wieder darauf zurückkommen können. Siehe [Suche und gespeicherte Suchen](../search/#gespeicherte-suche-speichern).

Eine Stelle bleibt so lange im Stream, wie die Einstellung für die Aufbewahrung sie behält. Monfil entfernt eine Stelle nicht, wenn das Unternehmen sie besetzt.
